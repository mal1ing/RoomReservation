# 화면 설계

## 일반 회원 화면

| ID | 화면 | 주요 기능 |
|---|---|---|
| M01 | 공간 목록 | 날짜·인원별 공간 조회, 부가 정보 펼치기 |
| M02 | 공간 상세 | 정책·요금 확인, 예약 시간 선택 |
| M03 | 로그인 | 네이버 로그인 |
| M04 | 결제 정보 확인 | 예약 요약, 금액, 취소 마감, 남은 시간 확인 |
| M05 | 결제 결과 | 예약 확정, 실패, 확인 중, 환불 진행 안내 |
| M06 | 내 예약 | 예약 목록·상세 조회, 취소 요청 |
| M07 | 내 불편 사항 | 접수 작성, 처리 상태·답변 조회 |

## 비회원 이용 및 로그인 안내

- 비회원도 공간 목록·상세·예약 가능 시간을 조회할 수 있다.
- 날짜·시간·인원을 선택할 수 있지만 임시 예약은 생성하지 않는다.
- 결제 정보 확인 버튼을 누르면 로그인 안내 팝업을 표시한다.
- 팝업에는 계속 둘러보기와 네이버 로그인 버튼을 제공한다.
- 로그인 후 선택 정보를 복원하고 서버에서 예약 가능 여부를 재검증한다.
- 선택 구간이 유효하지 않으면 이유를 안내하고 다시 선택하도록 한다.
